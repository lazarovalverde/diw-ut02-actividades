Qué vas a aprender

El hero es la primera impresión del restaurante: ocupa toda la pantalla, tiene una imagen de fondo con un overlay oscuro para que el texto sea legible, y el contenido queda perfectamente centrado con Flexbox. En esta práctica aprenderás a combinar capas de fondo con gradientes, a usar min-height con unidades de viewport para secciones de pantalla completa, y a escribir tipografía fluida con clamp() para que el titular se adapte a cualquier tamaño sin media queries.

Situación

El cliente quiere que al abrir la web de HANA lo primero que vea el visitante sea una imagen de ambiente del restaurante ocupando toda la pantalla, con el nombre del restaurante en grande, un subtítulo y dos botones: uno para reservar y otro para ver el menú. El texto debe ser perfectamente legible sobre la foto aunque sea oscura.

Lee las capas antes de escribir CSS El hero tiene tres capas superpuestas: la fotografía de fondo, un gradiente oscuro encima (el overlay que hace legible el texto), y el contenido centrado con Flexbox. Cada capa se declara de una forma distinta en CSS. Identifícalas en la maqueta antes de abrir el editor.

Unidades de viewport y clamp()

En el hero vas a usar por primera vez unidades relativas al tamaño de la ventana del navegador. Son imprescindibles para secciones de pantalla completa.

Unidad / funciónRelativa a…Cuándo usarla
vh 1% de la altura de la ventana visible Secciones de pantalla completa. min-height: 100vh = al menos toda la pantalla, crece si el contenido lo necesita.
vw 1% del ancho de la ventana visible Tipografía fluida (con cuidado), elementos que deben escalar con el ancho de pantalla.
svh 1% de la altura del viewport pequeño (mobile) En móvil, la barra del navegador reduce el viewport. svh es la alternativa segura a vh en móvil.
clamp(mín, preferido, máx) Tres valores: mínimo, valor fluido y máximo Tipografía que escala suavemente entre dos tamaños sin media queries. clamp(2rem, 5vw, 3.5rem) nunca será menor de 2rem ni mayor de 3.5rem.
🧠
height: 100vh vs min-height: 100vh height: 100vh fija la altura exacta — si el contenido crece más, desborda. min-height: 100vh garantiza al menos esa altura pero deja que crezca. Para un hero con contenido variable, min-height es siempre la opción correcta.

El overlay: cómo se apilan las capas de fondo

En CSS, background acepta varias capas separadas por comas. El navegador las apila de delante hacia atrás: la primera capa va encima, la última va detrás. El overlay es simplemente un gradiente semitransparente puesto delante de la imagen.

Cómo se lee el background con múltiples capas
.hero { background: /* Capa 1 — va DELANTE — el overlay oscuro */ linear-gradient( to bottom, hsl(0 0% 0% / 0.20), /* arriba: 20% opaco */ hsl(0 0% 0% / 0.70) /* abajo: 70% opaco — más oscuro para el texto */ ), /* Capa 2 — va DETRÁS — la fotografía */ url('img/hero-restaurante.jpg'); background-size: cover; /* la foto rellena sin dejar huecos */ background-position: center; /* centrada — la parte más importante queda visible */ }
💡
El gradiente no es un elemento HTML — es parte del fondo No hay ningún <div> de overlay en el HTML. El gradiente y la imagen se declaran juntos en la propiedad background, separados por una coma. El navegador los compone automáticamente. Menos HTML, mismo resultado visual.

Accesibilidad en el hero aria-label="Portada" en el <section> lo identifica como región de la página para lectores de pantalla. El <h1> es el titular principal de la página — solo debe haber uno. El texto del botón «Reservar mesa» es descriptivo: un usuario con lector de pantalla sabe exactamente qué hace sin necesitar el contexto visual.

Pasos

  1. Construye el fondo: imagen + overlay en una sola propiedad

    El hero necesita una fotografía de fondo que lo cubra completamente y un gradiente oscuro encima para que el texto blanco sea legible. Ambas cosas van en la misma declaración background, separadas por una coma. La foto debe cubrir toda la zona sin dejar huecos y estar centrada.

    Tu tarea
    1. Descarga o usa cualquier fotografía de ambiente de restaurante y guárdala en img/hero-restaurante.jpg.
    2. En .hero, declara el background con dos capas: primero el gradiente de overlay (de hsl(0 0% 0% / 0.20) a hsl(0 0% 0% / 0.70)), luego la imagen.
    3. Añade background-size: cover y background-position: center.
    4. Comprueba: la foto debe cubrir toda la sección sin deformarse ni dejar bordes blancos.
    .hero { background: /* ← TÚ: gradiente overlay — de 20% a 70% opaco */ /* ← TÚ: imagen de fondo */ ; /* ← TÚ: la foto cubre toda la sección sin dejar huecos */ /* ← TÚ: la parte más importante de la foto queda visible */ }
  2. Da altura a la sección y centra el contenido con Flexbox

    El hero debe ocupar como mínimo toda la altura de la pantalla. El contenido interior (.hero__contenido) tiene que quedar centrado horizontal y verticalmente, con los elementos en columna. Este es el mismo Flexbox de la nav, pero con el eje principal vertical.

    Tu tarea
    1. En .hero: usa la unidad de viewport que garantiza al menos toda la pantalla de alto, pero que permite que la sección crezca si el contenido lo necesita.
    2. Activa Flexbox en .hero para centrar .hero__contenido. Los ítems deben quedar centrados en los dos ejes. En la nav los ítems iban en fila — aquí van en columna.
    3. Añade padding: var(--space-20) var(--space-8) para que el contenido no toque los bordes en pantallas pequeñas.
    .hero { /* fondo del paso anterior... */ /* ← TÚ: al menos toda la pantalla de alto, pero puede crecer */ display: flex; /* ← TÚ: eje vertical — los ítems van en columna */ /* ← TÚ: centra en el eje principal (vertical) */ /* ← TÚ: centra en el eje cruzado (horizontal) */ padding: var(--space-20) var(--space-8); text-align: center; }
    💡
    El eje cambia con flex-direction Cuando flex-direction: row (por defecto), justify-content distribuye horizontalmente y align-items alinea verticalmente.
    Cuando flex-direction: column, los ejes se invierten: justify-content distribuye verticalmente y align-items alinea horizontalmente. Para centrar en los dos ejes, necesitas center en ambas propiedades.
  3. Estiliza la tipografía del hero

    El titular es el elemento más importante visualmente. Debe ser grande y adaptarse al tamaño de la pantalla sin necesitar media queries. Para eso existe clamp(): define un mínimo, un valor fluido y un máximo. El <em> dentro del titular tiene un color dorado que añade elegancia — se estiliza con el selector de elemento dentro del titular.

    Tu tarea
    1. En .hero__etiqueta: text-xs, peso 600, uppercase, letter-spacing: 0.2em, color dorado (hsl(35 90% 70%)).
    2. En .hero__titulo: Playfair Display, clamp(2rem, 5vw, 3.5rem) como font-size, peso 700, color blanco, line-height: 1.15, max-width: 14ch. Dentro, em en color dorado (hsl(35 90% 72%)) e itálica.
    3. En .hero__subtitulo: clamp(1rem, 2vw, 1.125rem), color hsl(0 0% 100% / 0.78), max-width: 44ch, line-height: 1.65.
    .hero__contenido { display: flex; flex-direction: column; align-items: center; gap: var(--space-5); /* espacio entre etiqueta, título, subtítulo y botones */ } .hero__etiqueta { font-size: var(--text-xs); font-weight: 600; letter-spacing: 0.2em; /* apertura amplia — típico de etiquetas de lujo */ text-transform: uppercase; color: hsl(35 90% 70%); /* dorado suave */ } .hero__titulo { font-family: var(--font-display); /* ← TÚ: font-size fluido con clamp(mínimo, fluido, máximo) */ font-weight: 700; color: white; line-height: 1.15; /* compacto — titulares grandes se leen mejor así */ max-width: 14ch; /* limita a ~14 caracteres — controla el salto de línea */ em { /* ← TÚ: color dorado e itálica para el énfasis */ } } .hero__subtitulo { /* ← TÚ: font-size fluido, color semitransparente, max-width y line-height */ }
    💡
    max-width: 14ch — la unidad de longitud de línea ch equivale al ancho del carácter «0» de la fuente actual. Es la unidad más natural para controlar cuántos caracteres caben en una línea. En tipografía, los titulares grandes suelen leerse mejor entre 10 y 20 caracteres por línea. 14ch fuerza el salto en el punto correcto sin necesitar un <br> en HTML para cada tamaño de pantalla.
  4. Estiliza los botones del hero

    El hero tiene dos botones: uno primario en dorado (el color de acento de HANA, que contrasta bien sobre fondo oscuro) y uno secundario tipo «ghost» (fondo transparente, solo borde blanco semitransparente). El botón ghost es habitual en heroes: es legible sobre fondos oscuros sin competir visualmente con el botón principal.

    Tu tarea
    1. En .hero__botones: Flexbox con gap: var(--space-4) y flex-wrap: wrap para que los botones pasen a columna en pantallas muy estrechas.
    2. En .hero__btn-primario: fondo var(--color-accent), color var(--color-ink), peso 600, text-lg, padding: 14px 28px, border-radius: var(--radius-sm), borde de 2px del mismo color accent. Anida :hover con fondo más oscuro y :focus-visible con outline: 3px solid white.
    3. En .hero__btn-secundario: fondo transparente, color blanco, borde 2px solid hsl(0 0% 100% / 0.45). En hover: borde blanco sólido y fondo hsl(0 0% 100% / 0.08).
    .hero__botones { display: flex; gap: var(--space-4); flex-wrap: wrap; /* si no caben en fila, se apilan */ } .hero__btn-primario { /* ← TÚ: botón dorado — todas las propiedades */ &:hover { /* ← TÚ: oscurece el dorado */ } &:focus-visible { outline: 3px solid white; outline-offset: 3px; } } .hero__btn-secundario { /* ← TÚ: botón ghost — transparente con borde blanco */ /* Hereda font-size, font-weight, padding y border-radius del primario */ /* (o copia las mismas propiedades de base) */ &:hover { /* ← TÚ: borde sólido + fondo muy sutil */ } &:focus-visible { outline: 3px solid white; outline-offset: 3px; } }
  5. Verifica el resultado
    Lista de verificación
    • La fotografía cubre toda la sección sin dejar bordes blancos ni deformarse.
    • El texto es legible sobre la foto — el overlay es suficientemente oscuro en la zona del texto.
    • El contenido está centrado horizontal y verticalmente dentro del hero.
    • El titular cambia de tamaño al redimensionar la ventana — nunca por debajo de 2rem ni por encima de 3.5rem. Compruébalo estrechando y ensanchando la ventana.
    • El subtítulo nunca supera los ~44 caracteres por línea — max-width: 44ch lo garantiza.
    • El botón dorado y el ghost son claramente diferentes. Ambos responden al hover y muestran foco con Tab.
    • La nav fija del paso anterior sigue visible encima del hero.
