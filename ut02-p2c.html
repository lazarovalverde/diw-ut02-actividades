Zonas de trabajo

header.site-header Zona 1 — fija la nav en la parte superior

La nav debe quedarse fija en la parte superior al hacer scroll. El contenido de debajo no debe quedar tapado por ella.

  • 1 La nav se queda fija en la ventana aunque se haga scroll — no en el flujo del documento.
  • 2 La nav ocupa todo el ancho horizontal de la ventana.
  • 3 La nav queda por encima de cualquier otro contenido que pueda solaparse con ella.
  • 4 El contenido de la página empieza justo debajo de la nav, sin quedar tapado. Esta propiedad va en body.
.site-header { /* 1 — fija respecto a la ventana */ top: 0; /* 2a — desde el borde izquierdo */ /* 2b — hasta el borde derecho */ /* 3 — por encima de todo */ } body { /* 4 — espacio superior igual a la altura de la nav */ }
nav.nav Zona 2 — el contenedor flex

El contenedor flex tiene tres hijos directos: logo, lista y botón. Al activar Flexbox, los tres pasan a fila automáticamente. Luego hay que distribuirlos y alinearlos.

  • 5 Los tres hijos directos pasan a comportarse en fila.
  • 6 El logo queda pegado a la izquierda y el botón a la derecha, con la lista en el espacio intermedio.
  • 7 Los tres hijos quedan centrados verticalmente dentro de los 64px de la nav.
.nav { background: var(--color-surface); box-shadow: var(--shadow-sm); padding: 0 var(--space-8); height: 64px; /* 5 — activa el modo flex */ /* 6 — distribuye a los extremos */ /* 7 — centra en el eje vertical */ }
ul.nav__lista y sus enlaces Zona 3 — la lista de enlaces

La lista pone sus ítems en fila con espacio uniforme entre ellos. El enlace activo tiene color y peso distintos y una línea debajo generada con CSS. El hover solo funciona en los enlaces que no son el activo.

  • 8 Los li aparecen en fila — la lista activa Flexbox igual que la nav.
  • 9 Hay espacio uniforme entre los ítems sin usar margin en cada uno. Usa var(--space-8).
  • 10 El enlace activo (.nav__enlace.activo) tiene color de marca y peso 600.
  • 11 El enlace activo tiene una línea de 2px bajo el texto, generada con ::after, sin ocupar espacio en el flujo. Necesita que el enlace sea el contexto de posicionamiento.
  • 12 Al pasar el cursor, solo cambian de color los enlaces que no son el activo.
  • 13 Al navegar con Tab, todos los enlaces muestran un anillo de foco visible.
.nav__lista { list-style: none; align-items: center; /* 8 — ítems en fila */ /* 9 — espacio entre ítems */ } .nav__enlace { font-size: var(--text-sm); font-weight: 500; color: var(--color-muted); text-decoration: none; letter-spacing: 0.03em; transition: color var(--transition-fast); /* 11a — necesario para anclar ::after */ padding-bottom: 2px; /* 10 — selector: enlace que además tiene clase activo */ &.activo { /* 11b — línea bajo el texto, fuera del flujo */ &::after { content: ''; /* 11c — coordenadas: justo bajo el texto */ left: 0; right: 0; height: 2px; background: var(--color-brand); border-radius: var(--radius-full); } } /* 12 — hover solo en los que no son el activo */ &:focus-visible { /* 13 — anillo de foco visible */ outline-offset: 4px; border-radius: var(--radius-sm); } }
a.nav__logo y a.nav__boton Zona 4 — logo y botón de reserva

El logo usa Playfair Display y responde al hover y al foco. El botón es btn-primary del design system.

  • 14 El logo tiene Playfair Display, tamaño 1.375rem, peso 700, color de marca, letter-spacing: 0.08em y sin subrayado. En hover oscurece ligeramente.
  • 15 El botón «Reservar» tiene el estilo completo de btn-primary del design system (tamaño base). Consúltalo en la guía de estilos.
.nav__logo { /* 14 — todas las propiedades del logo */ &:hover { /* color más oscuro */ } &:focus-visible { outline: 3px solid var(--color-brand); outline-offset: 4px; border-radius: var(--radius-sm); } } .nav__boton { /* 15 — propiedades de btn-primary (guía de estilos HANA) */ &:hover { background: var(--color-brand-dark); border-color: var(--color-brand-dark); } &:focus-visible { outline: 3px solid var(--color-brand); outline-offset: 3px; } }

Verificación

✓
Logo a la izquierda, botón a la derecha — sin floats ni márgenes manuales. Los cuatro enlaces de la lista están en fila con espacio uniforme usando solo gap. «Inicio» tiene color y peso distintos. Al hacer hover sobre él, no cambia. Hay una línea roja de 2px bajo «Inicio» generada con ::after, no con border-bottom. Al pasar el cursor por «Menú», «Nosotros» y «Contacto», cambian de color suavemente. Al navegar con Tab, cada elemento interactivo muestra un anillo de foco visible. Al hacer scroll, la nav permanece fija y el contenido pasa por debajo sin quedar tapado. En DevTools → Computed: la nav muestra display: flex y justify-content: space-between.
