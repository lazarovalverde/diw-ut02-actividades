Nuestra historia

Selecciona los mejores ingredientes de temporada, respeta los tiempos de la naturaleza y eleva cada plato a una experiencia estética. CSS con huecos — completa los 16

Los comentarios entre paréntesis describen el efecto visual que debe producir cada valor. Las propiedades ya están escritas — solo los valores son tuyos.
ZONA A · hero
.hero {
  min-height: /* ① */; /* ocupa toda la pantalla */
  background-image:
    linear-gradient(/* fade oscuro dado */),
    url('img/nori-hero.jpg');
  background-size: cover;
  display: /* ② */; /* activa flex */
  flex-direction: /* ③ */; /* apila elementos en columna */
  align-items: /* ④ */; /* centra en el eje cruzado */
  justify-content: /* ⑤ */; /* centra en el eje principal */
}

.hero-titulo {
  font-size: /* ⑥ */; /* clamp entre 2.5rem y 4.5rem, centro 6vw */
  max-width: /* ⑦ */; /* máximo 12 caracteres de ancho */
}

.btn-ghost {
  background: /* ⑧ */; /* sin relleno de color */
  border: 2px solid /* ⑨ */; /* blanco con 45% de opacidad */
  transition: filter 0.2s ease; /* dado */
}
ZONA B · grid menú
.menu-grid {
  display: /* ⑩ */; /* activa grid */
  grid-template-columns: repeat(/* ⑪ */, minmax(280px, 1fr));
  /* columnas automáticas, mínimo 280 px */
  gap: var(--s-6);
}
ZONA C · tipografía
.historia-texto {
  font-size: 1.0625rem; /* dado */
  line-height: 1.8; /* dado */
}

.historia-texto::first-letter {
  color: /* ⑫ */; /* color jade del sistema */
  font-family: var(--nori-serif); /* dado */
  font-size: 4rem; /* dado */
  float: left; /* dado */
}

.historia-texto::selection {
  background-color: /* ⑬ */; /* selección en jade */
  color: hsl(0 0% 100%); /* dado */
}
ZONA D · formulario
/* el campo de email ha sido tocado y tiene un valor inválido */
.field:/* ⑭ */ { /* pseudo-clase para input inválido tocado */
  &::after {
    content: attr(data-error);
    /* muestra el mensaje de error del atributo HTML */
    color: hsl(0 70% 55%); /* dado */
  }
}

/* el input tiene borde jade cuando está enfocado con teclado */
.reserva-form input:/* ⑮ */ { /* pseudo-clase para foco visible */
  outline: 2px solid var(--nori-jade);
  outline-offset: 2px;
}
ZONA E · tabla alérgenos
.alergenos-tabla {
  border-collapse: /* ⑯ */; /* fusiona los bordes adyacentes */
}

/* los estilos de thead, :nth-child(even), :hover y li::marker
   están dados en la práctica P8 — aquí solo se pide el ⑯ */

Guía de huecos

# Zona Descripción visual Concepto CSS
① Hero El hero ocupa exactamente la altura de la pantalla 100vh
② Hero Activa el modelo de caja flex flex
③ Hero Los hijos se apilan de arriba a abajo column
④ Hero Centra horizontalmente en un flex column center
⑤ Hero Centra verticalmente en un flex column center
⑥ Hero Tamaño de fuente fluido entre 2.5 rem y 4.5 rem clamp(2.5rem, 6vw, 4.5rem)
⑦ Hero El título no supera 12 caracteres de ancho 12ch
⑧ Hero El botón no tiene relleno de color visible transparent
⑨ Hero Borde blanco semitransparente (45% opacidad) hsl(0 0% 100% / 0.45)
⑩ Grid Activa el layout de cuadrícula grid
⑪ Grid Columnas automáticas que se adaptan al espacio auto-fit
⑫ Tipografía La primera letra usa el color verde jade del sistema var(--nori-jade)
⑬ Tipografía Al seleccionar texto, el fondo es verde jade var(--nori-jade)
⑭ Formulario Se activa cuando el input ha sido tocado y el valor es inválido user-invalid
⑮ Formulario Se activa cuando el foco proviene del teclado, no del ratón focus-visible
⑯ Tabla Los bordes de celdas adyacentes se fusionan en uno solo collapse
