Estructura HTML de la tabla

Anatomía de una tabla HTML

  • <table> — contenedor raíz
  • <thead> — fila(s) de cabecera (semántica + estilos)
  • <tbody> — filas de datos
  • <tfoot> — fila de pie (notas, totales)
  • <tr> — fila (table row)
  • <th> — celda de cabecera (negrita + centrado por defecto)
  • <td> — celda de dato

Escribe la tabla dentro de <section class="alergenos-seccion">. Copia esta estructura:

<table class="tabla-alergenos">

  <!-- Cabecera -->
  <thead>
    <tr>
      <th>Plato</th>
      <th>Descripción</th>
      <th>Alérgenos</th>
      <th>Precio</th>
    </tr>
  </thead>

  <!-- Datos -->
  <tbody>
    <tr>
      <td><strong>Edamame</strong></td>
      <td>Vainas de soja al vapor con sal marina</td>
      <td>
        <ul class="alergenos-lista">
          <li><span class="tag-alergeno">Soja</span></li>
        </ul>
      </td>
      <td>5,50 €</td>
    </tr>
    <!-- … añade los demás platos igual -->
  </tbody>

  <!-- Pie -->
  <tfoot>
    <tr>
      <td colspan="4">
        ⓘ Lista de alérgenos según el Reglamento (UE) 1169/2011.
      </td>
    </tr>
  </tfoot>

</table>
💡 colspan="4" hace que la celda del pie ocupe las 4 columnas. Sin él, el texto quedaría solo en la primera columna.

.tabla-alergenos — border-collapse y base

border-collapse

Por defecto, cada celda tiene su propio borde + espacio entre celdas (border-spacing). Con border-collapse: collapse los bordes adyacentes se fusionan en uno solo — el aspecto habitual de las tablas de datos.

Añade los estilos base de la tabla. Tu tarea: rellena los dos huecos.

.tabla-alergenos {
  width: 100%;                      /* ocupa todo el ancho */
  border-collapse: /* ① */;   /* fusiona los bordes de celdas */
  font-size: /* ② */;          /* texto pequeño: var(--text-sm) */
}

Tu tarea:

  • ① Valor que fusiona los bordes
  • ② Token del sistema para texto pequeño
3

thead tr y thead th — Cabecera oscura

:first-child y :last-child

Seleccionan el primer y último elemento hijo dentro de su contenedor. En una fila de cabecera th:first-child es la celda de la izquierda y th:last-child la de la derecha — útiles para redondear esquinas.

Copia el bloque. Tu tarea: rellena los cuatro huecos.

.tabla-alergenos {
  /* … lo del paso anterior … */

  /* —— cabecera —— */
  & thead tr {
    background: /* ③ */;     /* fondo: token color texto */
    color: /* ④ */;           /* letras: token color superficie */
  }

  & thead th {
    padding: var(--space-3) var(--space-4);
    text-align: left;
    font-weight: 600;
    letter-spacing: 0.04em;
  }

  /* primera columna de cabecera: redondea esquina superior izquierda */
  & thead th:first-child {
    border-radius: /* ⑤ */;    /* var(--radius-sm) 0 0 0 */
  }

  /* última columna de cabecera: redondea esquina superior derecha */
  & thead th:last-child {
    border-radius: /* ⑥ */;    /* 0 var(--radius-sm) 0 0 */
  }
}

Tu tarea:

  • ③ Token para el fondo oscuro de cabecera
  • ④ Token para el texto claro de cabecera
  • ⑤ Radio que solo redondea la esquina superior izquierda
  • ⑥ Radio que solo redondea la esquina superior derecha
💡 border-radius con 4 valores sigue el orden superior-izq, superior-der, inferior-der, inferior-izq (sentido horario desde arriba a la izquierda).
4

tbody td y tr:last-child td — Cuerpo de la tabla

:last-child para eliminar el borde final

Si ponemos border-bottom a todas las celdas, la última fila tendrá borde debajo del contenido — se ve raro si la tabla tiene bordes exteriores o está dentro de una card. tr:last-child td lo elimina selectivamente.

Tu tarea: rellena los tres huecos.

.tabla-alergenos {
  /* … pasos anteriores … */

  /* —— cuerpo —— */
  & tbody td {
    padding: var(--space-3) var(--space-4);
    border-bottom: /* ⑦ */;     /* 1px solid color borde */
    vertical-align: top;
  }

  /* última fila: sin borde inferior */
  & tbody tr:last-child td {
    border-bottom: /* ⑧ */;        /* quita el borde */
  }

  /* pie: separador superior más grueso */
  & tfoot td {
    padding: var(--space-3) var(--space-4);
    font-size: var(--text-xs);
    color: var(--color-sutil);
    font-style: italic;
    border-top: /* ⑨ */;          /* 2px solid color borde */
  }
}

Tu tarea:

  • ⑦ Borde inferior fino entre cada fila
  • ⑧ Valor para eliminar un borde
  • ⑨ Borde superior del pie, más grueso (2px)

tr:nth-child(even) — Filas alternas (zebra)

:nth-child()

Selecciona elementos según su posición dentro del padre. Los valores más usados:

  • :nth-child(odd) — filas impares (1ª, 3ª, 5ª…)
  • :nth-child(even) — filas pares (2ª, 4ª, 6ª…)
  • :nth-child(3) — exactamente la tercera
  • :nth-child(3n) — cada tres: 3ª, 6ª, 9ª…

Tu tarea: rellena los dos huecos para conseguir el patrón zebra.

.tabla-alergenos {
  /* … pasos anteriores … */

  /* filas pares: fondo ligeramente distinto */
  & tbody tr:nth-child(/* ⑩ */) {
    background: /* ⑪ */;    /* hsl(30 15% 97%) — gris cálido muy sutil */
  }
}

Tu tarea:

  • ⑩ Keyword para seleccionar filas pares
  • ⑪ Color de fondo tenue para las filas pares

tbody tr:hover — Resaltar fila al pasar el ratón

Hover en filas de tabla

tr:hover se aplica cuando el cursor entra en cualquier celda de esa fila. La transición se pone en el estado base (tr), no en el :hover, para que la animación funcione en las dos direcciones (entrada y salida).

Tu tarea: rellena los tres huecos.

.tabla-alergenos {
  /* … pasos anteriores … */

  /* transición en el estado base */
  & tbody tr {
    transition: /* ⑫ */;   /* background 0.15s ease */
  }

  /* color al pasar el ratón */
  & tbody tr:hover {
    background: /* ⑬ */;  /* token acento con baja opacidad */
  }
}

Tu tarea:

  • ⑫ Shorthand de transición: propiedad, duración y curva
  • ⑬ Token de acento dorado con opacidad baja (ya está en el design system)
⚠️ El :hover sobreescribirá el fondo de :nth-child(even) porque tiene más especificidad al combinarse con el selector padre. Eso es correcto — queremos que el hover siempre gane.

.alergenos-lista li::marker — Viñeta en color acento

::marker

Selecciona el marcador de un elemento de lista — el punto, número o símbolo que aparece delante del contenido. Permite cambiar su color, tamaño o incluso reemplazarlo con content, sin tocar el texto del elemento.

Antes de ::marker, la única forma de colorear la viñeta era envolverla en un <span>.

Tu tarea: rellena los dos huecos.

.alergenos-lista {
  list-style: disc;
  padding-left: var(--space-5);
  display: flex;
  flex-direction: column;
  gap: var(--space-1);

  & li::marker {
    color: /* ⑭ */;     /* token color acento dorado */
    font-size: /* ⑮ */;  /* un poco más grande: 1.1em */
  }
}

Tu tarea:

  • ⑭ Token del color de acento dorado
  • ⑮ Tamaño relativo para que el punto sea ligeramente mayor que el texto
8

td[colspan] — Selectores de atributo (bonus)

Selectores de atributo

Seleccionan elementos por el valor (o presencia) de un atributo HTML:

  • [attr] — existe el atributo, sea cual sea su valor
  • [attr="valor"] — atributo con valor exacto
  • [attr^="inicio"] — valor empieza por "inicio"
  • [attr*="parte"] — valor contiene "parte"

Ya los usaste en P5 con [type="email"] y [type="date"].

El pie usa colspan="4" para ocupar toda la fila. Podemos apuntarlo directamente por ese atributo, sin necesidad de clase:

/* versión alternativa sin usar tfoot — solo para práctica */
td[colspan] {
  font-size: var(--text-xs);
  color: var(--color-sutil);
  font-style: italic;
}

/* o con valor exacto */
td[colspan="4"] {
  border-top: 2px solid var(--color-borde);
}
💡 No hace falta añadir este CSS a tu práctica — es solo para ver cómo funciona el selector de atributo en contexto real.
