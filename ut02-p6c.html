CSS — rellena los 16 huecos

/* ── ZONA 1: tabla base ── */
.tabla-alergenos {
  width: 100%;                           /* ocupa todo el ancho */
  border-collapse: /* ① */;          /* fusiona los bordes */
  font-size: /* ② */;               /* texto pequeño del sistema */

  /* ── ZONA 2: cabecera ── */
  & thead tr {
    background: /* ③ */;              /* fondo muy oscuro */
    color: /* ④ */;                  /* texto sobre fondo oscuro */
  }
  & thead th {
    padding: var(--space-3) var(--space-4);
    text-align: left;
    font-weight: 600;
    letter-spacing: 0.04em;
  }
  & thead th:first-child {
    border-radius: /* ⑤ */;           /* solo esquina sup-izq */
  }
  & thead th:last-child {
    border-radius: /* ⑥ */;           /* solo esquina sup-der */
  }

  /* ── ZONA 3: celdas del cuerpo ── */
  & tbody td {
    padding: var(--space-3) var(--space-4);
    border-bottom: /* ⑦ */;          /* línea fina entre filas */
    vertical-align: top;
  }
  & tbody tr:last-child td {
    border-bottom: /* ⑧ */;          /* elimina borde última fila */
  }

  /* ── ZONA 4: filas alternas ── */
  & tbody tr:nth-child(/* ⑨ */) {
    background: /* ⑩ */;             /* gris cálido muy sutil */
  }

  /* ── ZONA 5: hover sobre fila ── */
  & tbody tr {
    transition: /* ⑪ */;            /* background 0.15s ease */
  }
  & tbody tr:hover {
    background: /* ⑫ */;             /* token acento dorado suave */
  }

  /* ── ZONA 6: pie de tabla ── */
  & tfoot td {
    padding: var(--space-3) var(--space-4);
    font-size: /* ⑬ */;              /* más pequeño que el cuerpo */
    color: var(--color-sutil);
    font-style: italic;
    border-top: /* ⑭ */;             /* separador grueso (2px) */
  }
}

/* ── ZONA 6 (cont.): viñeta de alérgenos ── */
.alergenos-lista {
  list-style: disc;
  padding-left: var(--space-5);
  display: flex;
  flex-direction: column;
  gap: var(--space-1);

  & li::marker {
    color: /* ⑮ */;               /* punto en color acento dorado */
    font-size: /* ⑯ */;           /* punto algo más grande: 1.1em */
  }
}

# Zona Qué debes escribir Pista
① tabla base Valor que hace que los bordes de celdas adyacentes se fusionen en uno solo Opuesto a separate
② tabla base Token del sistema para texto pequeño (0.875 rem) --text-??
③ thead Token para el fondo muy oscuro de la cabecera El mismo que usan los badges del código de práctica
④ thead Token para el texto blanco/claro sobre fondo oscuro --color-sup???
⑤ thead Radio que redondea solo la esquina superior izquierda 4 valores en orden horario: TL TR BR BL
⑥ thead Radio que redondea solo la esquina superior derecha 4 valores: 0 TL→0, TR→radio, BR→0, BL→0
⑦ tbody td Borde inferior fino de 1px entre cada fila del cuerpo 1px solid var(--color-???)
⑧ tbody td Valor para eliminar el borde inferior de la última fila Una sola palabra
⑨ :nth-child Keyword para seleccionar filas pares (2ª, 4ª, 6ª…) Opuesto a odd
⑩ :nth-child Color de fondo gris cálido muy sutil para las filas pares hsl(30 15% 97%)
⑪ :hover Shorthand de transición sobre la propiedad background, 0.15 s, curva suave La transición va en el estado base, no en :hover
⑫ :hover Token del design system para el acento dorado con baja opacidad --color-acento-???
⑬ tfoot Token de tamaño de texto más pequeño que --text-sm --text-??
⑭ tfoot Borde superior del pie, más grueso que los bordes de fila (2px) 2px solid var(--color-???)
⑮ tfoot Token del color dorado de acento para colorear el punto de lista --color-acento a secas
⑯ tfoot Tamaño del marcador ligeramente mayor que el texto del elemento Valor relativo con em, algo por encima de 1
