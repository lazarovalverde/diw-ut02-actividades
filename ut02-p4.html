Qué vas a aprender

La sección del menú muestra las cards en una rejilla. Flexbox resuelve una dimensión — aquí necesitas dos: filas y columnas. Para eso existe CSS Grid. Aprenderás a definir columnas con la unidad fr, a usar repeat() para no repetir código, y a crear una rejilla que se adapta sola al ancho disponible con auto-fit y minmax() — sin una sola media query.

Situación

El cliente quiere una página de menú donde las cards se organicen en tres columnas en pantalla grande, pasen a dos en tablet y a una en móvil — automáticamente, sin media queries. Encima de la rejilla, una cabecera con título y botones de filtro por categoría.

Grid vs Flexbox — cuándo usar cada uno

Flexbox y Grid no son rivales — son herramientas para problemas distintos.

Flexbox vs Grid
🧠
La regla en una frase ¿El layout viene del contenido (ítems con tamaños distintos que fluyen)? → Flexbox.
¿El layout es una estructura definida y el contenido se adapta a ella? → Grid.
En la práctica: nav, botones, pie de card → Flexbox. Rejillas de cards, páginas → Grid.

La unidad fr y la función repeat()

fr (fracción) representa una parte del espacio disponible en el contenedor. Es la unidad específica de Grid.

/* Sin fr — tienes que calcular los porcentajes tú */ grid-template-columns: 33.33% 33.33% 33.33%; /* incómodo, error de redondeo */ /* Con fr — el navegador calcula */ grid-template-columns: 1fr 1fr 1fr; /* tres columnas iguales */ grid-template-columns: 1fr 2fr 1fr; /* la del medio mide el doble */ /* Con repeat() — evitar repetición */ grid-template-columns: repeat(3, 1fr); /* equivale a 1fr 1fr 1fr */ /* La rejilla adaptable — el patrón más usado */ grid-template-columns: repeat(auto-fit, minmax(260px, 1fr)); /* ↑ ↑ ↑ crea las mínimo crece hasta que quepan 260px llenar (1fr) */
💡
auto-fit vs auto-fill auto-fill crea columnas vacías para llenar el espacio si faltan ítems.
auto-fit colapsa las columnas vacías y deja que las ocupadas crezcan.
Para cards: siempre auto-fit — si solo hay una card, ocupa todo el ancho.

Código de partida

Añade una nueva página menu.html. Reutiliza la nav copiando el <header> del index.html.

<!-- menu.html --> <section class="menu" aria-labelledby="menu-titulo"> <div class="menu__contenedor"> <header class="menu__cabecera"> <p class="menu__etiqueta">Nuestra carta</p> <h2 class="menu__titulo" id="menu-titulo">El menú de HANA</h2> <p class="menu__desc">Producto de temporada, técnica japonesa.</p> </header> <div class="menu__filtros" role="group" aria-label="Filtrar por categoría"> <button class="menu__filtro menu__filtro--activo">Todos</button> <button class="menu__filtro">Nigiris</button> <button class="menu__filtro">Rolls</button> <button class="menu__filtro">Tempura</button> <button class="menu__filtro">Postres</button> </div> <div class="menu__grid"> <!-- Copia aquí los article.card de la P1, al menos 6 --> </div> </div> </section>

Pasos

  1. Observa la rejilla sin CSS Grid

    Abre el archivo sin CSS — las cards se apilan en una columna. Ese es el comportamiento por defecto que vas a cambiar.

    Tu tarea
    1. Añade el HTML con al menos seis cards copiadas de la P1.
    2. Ábrelo sin CSS de rejilla. Observa que las cards ocupan todo el ancho.
  2. Crea la rejilla adaptable

    Con una sola línea de grid-template-columns usando auto-fit y minmax(), la rejilla se adapta a cualquier ancho sin media queries.

    Tu tarea
    1. En .menu__grid: activa Grid y crea columnas que se adapten automáticamente. Mínimo 260px por columna, crecen hasta llenar el espacio.
    2. Añade gap: var(--space-6).
    3. Redimensiona la ventana. Observa cómo las columnas aparecen y desaparecen solas.
    .menu__grid { /* ← TÚ: activa Grid */ /* ← TÚ: columnas adaptables — mínimo 260px, máximo 1fr */ /* ← TÚ: espacio entre celdas */ }
    💡
    Por qué minmax(260px, 1fr) y no solo 260px Con solo 260px, las columnas siempre miden exactamente 260px y dejan espacio vacío a la derecha. Con minmax(260px, 1fr): mínimo 260px, pero si sobra espacio, se reparte. Sin huecos, sin media queries.
  3. Estiliza la cabecera de la sección

    Etiqueta, título y descripción centrados con jerarquía visual clara.

    Tu tarea
    1. .menu: fondo var(--color-bg), padding: var(--space-20) var(--space-8).
    2. .menu__contenedor: max-width: 1200px, margin: 0 auto.
    3. .menu__cabecera: text-align: center, margin-bottom: var(--space-10).
    4. .menu__etiqueta: igual que .hero__etiqueta — text-xs, uppercase, letter-spacing 0.2em, color accent.
    5. .menu__titulo: Playfair Display, text-4xl, peso 700.
    6. .menu__desc: text-base, color muted, max-width: 48ch, margin: 0 auto.
    .menu { background: var(--color-bg); padding: var(--space-20) var(--space-8); } .menu__contenedor { max-width: 1200px; margin: 0 auto; } .menu__cabecera { text-align: center; margin-bottom: var(--space-10); } .menu__etiqueta { font-size: var(--text-xs); font-weight: 600; letter-spacing: 0.2em; text-transform: uppercase; color: var(--color-accent); margin-bottom: var(--space-2); } .menu__titulo { font-family: var(--font-display); font-size: var(--text-4xl); font-weight: 700; color: var(--color-ink); margin-bottom: var(--space-3); } .menu__desc { font-size: var(--text-base); color: var(--color-muted); max-width: 48ch; margin: 0 auto; }
  4. Estiliza los botones de filtro

    Píldoras en fila centradas. Activo con fondo de marca. Hover solo en los no activos — el mismo patrón :not() de la nav, ahora lo aplicas tú solo.

    Tu tarea
    1. .menu__filtros: Flexbox centrado, gap: var(--space-2), flex-wrap: wrap, margin-bottom: var(--space-8).
    2. .menu__filtro: fondo blanco, color muted, borde var(--color-border), border-radius: var(--radius-full), padding: var(--space-2) var(--space-5), text-sm, peso 500, cursor pointer, transition: all var(--transition-fast).
    3. &.menu__filtro--activo: fondo brand, color blanco, borde brand.
    4. Hover solo en los no activos con :not(.menu__filtro--activo): borde y color brand.
    .menu__filtros { display: flex; gap: var(--space-2); flex-wrap: wrap; justify-content: center; margin-bottom: var(--space-8); } .menu__filtro { background: var(--color-surface); color: var(--color-muted); border: 1.5px solid var(--color-border); border-radius: var(--radius-full); padding: var(--space-2) var(--space-5); font-size: var(--text-sm); font-weight: 500; font-family: var(--font-body); cursor: pointer; transition: all var(--transition-fast); &--activo { background: var(--color-brand); color: white; border-color: var(--color-brand); } /* ← TÚ: hover solo en los que no son --activo */ &:focus-visible { outline: 3px solid var(--color-brand); outline-offset: 2px; } }
    🧠
    BEM con modificadores — &--activo dentro del bloque El modificador menu__filtro--activo se anida con &--activo. El CSS de ese estado queda junto al estado normal — más fácil de leer y mantener.
  5. Reutiliza las cards de la P1

    Las cards ya están definidas. En el grid actúan como ítems — el grid les da el ancho de la columna y las estira a la misma altura por fila gracias a align-items: stretch (valor por defecto de Grid).

    Tu tarea
    1. Copia al menos 6 article.card dentro de .menu__grid.
    2. Verifica que todas las cards de la misma fila tienen la misma altura.
    3. Comprueba el overlay de Grid en DevTools: Inspector → haz clic en el icono de rejilla junto a .menu__grid.
    💡
    Grid iguala alturas automáticamente — Flexbox no Grid estira todos los ítems de una fila para que midan lo mismo (align-items: stretch). Con Flexbox en varias filas (flex-wrap: wrap) esto no ocurre — cada fila es independiente y las alturas no se alinean. Para rejillas de cards, Grid siempre da mejor resultado.
  6. Verifica con DevTools
    Lista de verificación
    • Pantalla ancha: 3 o 4 columnas. Al estrechar: 2, luego 1 — sin media queries.
    • Cards de la misma fila con la misma altura.
    • Espacio uniforme entre celdas usando solo gap — sin margin en las cards.
    • Filtro activo con fondo rojo. Los demás cambian al hacer hover.
    • Overlay de Grid visible en DevTools.
