Unidades relativas: rem vs em

rem y em

  • rem (root em) — relativo al font-size del <html>. Por defecto 16 px. Predecible: 1.5rem = 24px siempre.
  • em — relativo al font-size del elemento actual. Se acumula si anidas: un em dentro de otro em multiplica.
  • Usa rem para tamaños de texto y espaciados globales. Usa em para ajustes proporcionales al componente (padding de un botón que crece con su texto, por ejemplo).

Los tokens del design system ya usan rem. Aquí ves la equivalencia:

/* tokens — ya están definidos en :root */
--text-xs:   0.75rem;    /* 12px */
--text-sm:   0.875rem;   /* 14px */
--text-base: 1rem;       /* 16px */
--text-lg:   1.125rem;   /* 18px */
--text-xl:   1.25rem;    /* 20px */
--text-2xl:  1.5rem;     /* 24px */
--text-3xl:  1.875rem;   /* 30px */
--text-4xl:  2.25rem;    /* 36px */

Fíjate en que el cuerpo del texto de la sección usa 1.0625rem (17 px) — un valor entre tokens para un tamaño de lectura cómodo:

.historia__cuerpo {
  font-size: /* ① */;     /* 17px — entre text-base (16) y text-lg (18) */
  line-height: /* ② */;   /* interlineado amplio para lectura: 1.8 */
  color: hsl(20 10% 30%);
  max-width: 60ch;        /* máximo 60 caracteres de ancho */
}

Tu tarea:

  • ① Tamaño de 17 px expresado en rem (base 16 px)
  • ② Interlineado de 1.8 (sin unidad)

Google Fonts y @font-face

Dos formas de cargar fuentes externas

  • Google Fonts (CDN) — enlace en el HTML. Rápido de usar, dependes de red externa.
  • @font-face — descargas los archivos a tu servidor. Control total, sin dependencia externa, imprescindible en proyectos de producción.

En HANA usamos Google Fonts. El enlace ya está en el <head> de la página:

<!-- en el <head> del HTML -->
<link rel="preconnect" href="https://fonts.googleapis.com">
<link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700
      &family=Playfair+Display:ital,wght@0,700;1,400&display=swap"
      rel="stylesheet">

El equivalente con @font-face (archivos descargados en fonts/):

@font-face {
  font-family: 'Playfair Display';
  src: url('fonts/PlayfairDisplay-Bold.woff2') format('woff2');
  font-weight: 700;
  font-style: normal;
  font-display: swap;  /* muestra fallback hasta que cargue */
}

Ahora usa las fuentes en la sección. Tu tarea: rellena los dos huecos.

.historia__titulo {
  font-family: /* ③ */;    /* fuente serif del design system */
  font-size: var(--text-4xl);
  font-weight: 700;
  line-height: 1.15;
  color: var(--color-texto);
  margin-bottom: var(--space-6);
}

.historia__etiqueta {
  font-family: /* ④ */;    /* fuente sans-serif del design system */
  font-size: var(--text-xs);
  font-weight: 700;
  letter-spacing: 0.15em;
  text-transform: uppercase;
  color: var(--color-acento);
}

::first-letter — Capital destacada (drop cap)

::first-letter

Selecciona la primera letra del primer elemento de texto de un bloque. Solo funciona en elementos de bloque (p, div…). Permite crear la clásica capital decorada de los textos editoriales.

Para hacer drop cap (letra que desciende): float: left + ajuste de line-height y márgenes.

Tu tarea: rellena los cuatro huecos para conseguir la capital dorada.

.historia__cuerpo p:first-child::first-letter {
  font-family: /* ⑤ */;     /* serif para la capital */
  font-size: /* ⑥ */;        /* tamaño grande: 4rem */
  font-weight: 700;
  color: /* ⑦ */;           /* token color acento dorado */
  float: /* ⑧ */;           /* el texto fluye a su derecha */
  line-height: 0.8;
  margin-right: 0.12em;
  margin-top: 0.08em;
}

Tu tarea:

  • ⑤ Token de la fuente serif
  • ⑥ Tamaño grande expresado en rem
  • ⑦ Token del color dorado de acento
  • ⑧ Valor de float que hace que el texto fluya a la derecha de la letra
💡 ::first-letter solo funciona sobre el primer elemento <p> del contenedor. Por eso el selector usa p:first-child::first-letter — apunta al primer párrafo, y de ese párrafo, a su primera letra.

::selection — Color de selección de texto

::selection

Se aplica a la parte del texto que el usuario ha seleccionado con el ratón. Solo acepta un subconjunto de propiedades CSS: color, background-color, text-shadow.

Es un detalle de acabado que marca la diferencia en sitios de lectura — el azul por defecto del navegador rompe la paleta del diseño.

Tu tarea: rellena los dos huecos. Luego selecciona el texto de la demo para comprobar el efecto.

.historia__cuerpo ::selection {
  background: /* ⑨ */;   /* color acento dorado */
  color: /* ⑩ */;         /* blanco puro: hsl(0 0% 100%) */
}

Tu tarea:

  • ⑨ Token del color de fondo al seleccionar
  • ⑩ Color del texto seleccionado (contraste máximo sobre dorado)

Legibilidad: line-height, letter-spacing, max-width ch

Las tres palancas de legibilidad

  • line-height — espacio entre líneas. Para cuerpo de texto: 1.6–1.8. Para títulos grandes: 1.1–1.2 (más ancho se ve pesado).
  • letter-spacing — espacio entre letras. Texto en mayúsculas: 0.05–0.15em. Cuerpo de texto: mejor dejarlo a 0 o valores mínimos.
  • max-width: 60ch — limita la línea a ~60 caracteres. La unidad ch = ancho del carácter "0" en la fuente actual. Por encima de 75 ch la lectura se fatiga.

Tu tarea: completa la etiqueta "NUESTRA HISTORIA" con buen espaciado.

.historia__etiqueta {
  /* … font-family, font-size, font-weight ya dados arriba … */
  letter-spacing: /* ⑪ */;   /* separación generosa para mayúsculas: 0.15em */
  text-transform: /* ⑫ */;   /* todo en mayúsculas */
}

Tu tarea:

  • ⑪ Espaciado entre letras expresado en em
  • ⑫ Valor que convierte el texto a mayúsculas por CSS
