Zonas de trabajo

article.card Zona 1 — el contenedor

La card debe tener un ancho máximo de 300px y estar centrada horizontalmente. Fíjate en la maqueta: tiene esquinas redondeadas, sombra y el badge flota sobre la imagen sin empujar el contenido. Al pasar el cursor, se eleva suavemente.

  • 1 La card no debe superar 300px de ancho, pero sí adaptarse si la pantalla es más estrecha.
  • 2 La card debe estar centrada horizontalmente en su contenedor.
  • 3 Los contenidos de la card no deben sobresalir de las esquinas redondeadas.
  • 4 El badge puede posicionarse en coordenadas exactas dentro de la card.
  • 5 La elevación y la sombra cambian de forma suave al pasar el cursor. Escribe la propiedad que lo hace posible (en el estado normal, no en el hover).
  • 6 En hover: la card sube 2px sin desplazar otros elementos. La sombra crece a --shadow-lg.
.card { /* 1 */ /* 2 */ background: var(--color-surface); border-radius: var(--radius-lg); /* 3 */ box-shadow: var(--shadow-md); /* 4 */ /* 5 */ &:hover { /* 6a — sube 2px sin mover el flujo */ /* 6b — sombra más pronunciada */ } }
img.card__imagen Zona 2 — la imagen

La imagen ocupa todo el ancho de la card y tiene una altura fija de 180px. No se deforma aunque sus proporciones originales sean distintas. No hay espacio extra entre la imagen y el borde inferior de la zona.

  • 7 La imagen no debe dejar un pequeño hueco en su parte inferior. Recuerda qué tipo de elemento es <img> por defecto.
  • 8 La imagen rellena los 180px de alto sin deformarse ni mostrar barras negras.
.card__imagen { /* 7 — elimina el espacio inline bajo la imagen */ width: 100%; height: 180px; /* 8 — rellena sin deformar */ }
span.card__badge Zona 3 — el badge

El badge aparece en la esquina superior derecha de la imagen, a 12px de los bordes. No ocupa espacio en el flujo: ni la imagen ni el cuerpo de la card se ven afectados por su presencia.

  • 9 El badge flota sobre la imagen sin empujar ningún otro elemento.
  • 10 El badge está a 12px del borde superior de la card.
  • 11 El badge está a 12px del borde derecho de la card.
.card__badge { /* 9 — sale del flujo, se posiciona respecto al padre posicionado */ /* 10 */ /* 11 */ background: var(--color-accent); color: var(--color-ink); font-size: var(--text-xs); font-weight: 700; font-family: var(--font-body); padding: 4px 12px; border-radius: var(--radius-full); letter-spacing: 0.04em; }
div.card__cuerpo y sus hijos Zona 4 — el cuerpo

El cuerpo tiene 20px de espacio interior por los cuatro lados. Los badges de alérgenos aparecen en fila, no apilados. El pie separa precio y botón a los extremos con una línea horizontal sobre él. Todo el bloque va anidado dentro de .card { }.

  • 12 Los badges de alérgenos (li) aparecen en fila y respetan su padding y borde.
  • 13 En el pie, el precio queda pegado a la izquierda y el botón a la derecha.
  • 14 El botón tiene el estilo completo de btn-primary del design system (tamaño base). Consúltalo en la guía de estilos.
.card { /* propiedades de la zona 1 */ .card__imagen { /* propiedades de la zona 2 */ } .card__badge { /* propiedades de la zona 3 */ } .card__cuerpo { padding: var(--space-5); } .card__categoria { font-size: var(--text-xs); font-weight: 600; letter-spacing: 0.1em; text-transform: uppercase; color: var(--color-brand); margin-bottom: var(--space-2); } .card__titulo { font-family: var(--font-display); font-size: var(--text-xl); font-weight: 600; color: var(--color-ink); line-height: var(--lh-snug); margin-bottom: var(--space-2); } .card__descripcion { font-size: var(--text-sm); color: var(--color-muted); line-height: var(--lh-body); margin-bottom: var(--space-3); } .card__alergenos { list-style: none; margin-bottom: var(--space-4); } .card__alergen { /* 12 — display que los pone en fila respetando padding y borde */ font-size: 0.65rem; font-weight: 600; letter-spacing: 0.06em; text-transform: uppercase; padding: 2px 8px; border-radius: var(--radius-full); border: 1px solid; margin-right: var(--space-2); } .card__alergen--pescado { color: hsl(210 70% 40%); border-color: hsl(210 70% 70%); background: hsl(210 70% 96%); } .card__alergen--sesamo { color: hsl(30 70% 40%); border-color: hsl(30 70% 70%); background: hsl(30 70% 96%); } .card__pie { display: flex; /* 13 — precio a un extremo, botón al otro */ align-items: center; padding-top: var(--space-3); border-top: 1px solid var(--color-border); } .card__precio { font-family: var(--font-display); font-size: var(--text-2xl); font-weight: 700; color: var(--color-brand); } .card__boton { /* 14 — propiedades de btn-primary base (guía de estilos HANA) */ &:hover { background: var(--color-brand-dark); border-color: var(--color-brand-dark); } &:focus-visible { outline: 3px solid var(--color-brand); outline-offset: 3px; } } }
📐
El CSS está organizado siguiendo el orden de aparición de los elementos en el HTML: primero el contenedor, luego la imagen, el badge y finalmente el cuerpo con sus hijos. Esta es la convención en proyectos profesionales.

Verificación

Cuando termines, comprueba estos puntos antes de entregar:

✓
La card mide máximo 300px y está centrada. Al estrechar la ventana se adapta. La imagen ocupa 180px de alto sin deformarse ni dejar hueco inferior. El badge está en la esquina superior derecha sin empujar otros elementos. Los badges de alérgenos aparecen en fila, no apilados. El precio y el botón están en los extremos del pie. El hover eleva la card de forma suave con sombra creciente. El botón muestra un anillo de foco al navegar con Tab.
