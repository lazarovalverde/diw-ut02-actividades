/* ── ZONA 1: cuerpo del texto ── */
.historia__cuerpo {
  font-size: /* ① */;      /* 17px = 1.0625rem */
  line-height: /* ② */;   /* interlineado amplio para lectura */
  color: hsl(20 10% 30%);
  max-width: 60ch;        /* ancho máximo en caracteres */
}

/* ── ZONA 2: etiqueta "NUESTRA HISTORIA" ── */
.historia__etiqueta {
  font-family: /* ③ */;   /* fuente sans-serif del sistema */
  font-size: var(--text-xs);
  font-weight: 700;
  letter-spacing: /* ④ */;  /* espaciado generoso: 0.15em */
  text-transform: /* ⑤ */;  /* todo en mayúsculas */
  color: var(--color-acento);
}

/* ── ZONA 3: título ── */
.historia__titulo {
  font-family: /* ⑥ */;   /* fuente serif del sistema */
  font-size: var(--text-4xl);
  font-weight: 700;
  line-height: 1.15;
  color: var(--color-texto);
}

/* ── ZONA 4: capital decorada (drop cap) ── */
.historia__cuerpo p:first-child::first-letter {
  font-family: /* ⑦ */;   /* serif para la capital */
  font-size: /* ⑧ */;      /* tamaño muy grande: 4rem */
  font-weight: 700;
  color: /* ⑨ */;          /* token acento dorado */
  float: /* ⑩ */;          /* el texto fluye a su derecha */
  line-height: 0.8;
  margin-right: 0.12em;
  margin-top: 0.08em;
}

/* ── ZONA 5: color de selección ── */
.historia__cuerpo ::selection {
  background: /* ⑪ */;   /* fondo al seleccionar: token acento */
  color: /* ⑫ */;         /* texto: blanco puro */
}

/* ── ZONA 6: firma ── */
.historia__firma-nombre {
  font-family: var(--font-serif);
  font-style: /* ⑬ */;     /* cursiva */
  font-size: var(--text-lg);
}
.historia__firma-cargo {
  font-size: var(--text-xs);
  color: var(--color-sutil);
  letter-spacing: /* ⑭ */;  /* espaciado sutil: 0.05em */
}

Guía de huecos

# Zona Qué debes escribir Pista
① cuerpo 17 px expresados en rem (base: 16 px) 17 ÷ 16 = ?
② cuerpo Interlineado amplio para lectura (sin unidad) Entre 1.6 y 2.0
③ etiqueta Token de fuente sin serifa del design system --font-???
④ etiqueta Espaciado entre letras generoso para texto en mayúsculas 0.15em
⑤ etiqueta Valor que convierte el texto a mayúsculas por CSS text-transform: ???
⑥ título Token de fuente con serifa del design system --font-???
⑦ ::first-letter Token de fuente serif para la capital Mismo que el título
⑧ ::first-letter Tamaño muy grande de la capital (4 rem) Sin token, escríbelo directo
⑨ ::first-letter Token del color dorado de acento para la capital --color-acento
⑩ ::first-letter Valor de float que hace que el resto del texto fluya a la derecha Una sola palabra
⑪ ::selection Color de fondo al seleccionar texto Token acento dorado
⑫ ::selection Color del texto seleccionado para máximo contraste sobre fondo dorado Blanco puro en hsl
⑬ firma Valor de font-style para texto en cursiva Una sola palabra
⑭ firma Espaciado sutil entre letras del cargo (0.05 em) Menor que el de la etiqueta
