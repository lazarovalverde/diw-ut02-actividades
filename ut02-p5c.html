Darás estilo completo al formulario de reserva de HANA: campos que responden al foco con teclado, mensajes de error que aparecen solos tras una entrada incorrecta, texto placeholder atenuado y un asterisco automático en campos obligatorios, todo sin JavaScript.

CSS que debes completar — 16 huecos

/* ─── ZONA 1: section y form ─── */ .reserva { padding: var(--space-10) 0; background: var(--color-bg); } .reserva__contenedor { max-width: 560px; margin: 0 auto; padding: 0 var(--space-6); } .reserva__form { background: var(--color-surface); border-radius: var(--radius-lg); padding: var(--space-8); box-shadow: var(--shadow-md); } /* ─── ZONA 2: cabecera ─── */ .reserva__titulo { font-family: /* ① */; /* tipografía de display del design system */ font-size: var(--text-2xl); font-weight: 700; margin-bottom: var(--space-1); } .reserva__subtitulo { font-size: var(--text-sm); color: /* ② */; /* texto atenuado */ margin-bottom: var(--space-6); } /* ─── ZONA 3: estructura de campo ─── */ .campo { display: flex; flex-direction: column; gap: var(--space-1); margin-bottom: var(--space-5); position: /* ③ */; /* ancla el ::after del mensaje de error */ } /* asterisco en labels de campos obligatorios */ .campo:has(.campo__input:required) .campo__label::after { content: /* ④ */; /* ' *' con espacio antes */ color: /* ⑤ */; /* color corporativo HANA */ } /* ─── campo base y placeholder ─── */ .campo__input { width: 100%; padding: var(--space-3) var(--space-4); border: 1px solid var(--color-border); border-radius: var(--radius-sm); font-family: var(--font-body); font-size: var(--text-base); color: var(--color-ink); outline: none; transition: border-color 0.15s, box-shadow 0.15s; &::placeholder { color: /* ⑥ */; /* color muy suave, casi gris beige */ font-style: /* ⑦ */; /* en cursiva */ } /* ─── ZONA 4: foco por teclado ─── */ &:focus-visible { border-color: /* ⑧ */; /* borde de marca al enfocar */ box-shadow: /* ⑨ */; /* halo de 3px al 15% de opacidad */ } /* ─── ZONA 5: estado de error ─── */ &:user-invalid { border-color: /* ⑩ */; /* color de error del design system */ background: /* ⑪ */; /* fondo rosa muy suave */ } } /* mensaje de error inyectado como ::after */ .campo:has(.campo__input:user-invalid)::after { content: /* ⑫ */; /* lee el attr data-error del .campo padre */ display: block; font-size: var(--text-xs); color: var(--color-error); margin-top: var(--space-1); } /* tipo date y time interactivos */ .campo__input[type="date"], .campo__input[type="time"] { cursor: /* ⑬ */; /* indica que es clickable */ } /* textarea redimensionable solo en alto */ textarea.campo__input { resize: /* ⑭ */; /* solo puede crecer en alto */ min-height: 5rem; } /* ─── ZONA 6: botón de envío ─── */ .reserva__form .btn-primary { width: /* ⑮ */; /* ocupa todo el ancho del form */ margin-top: var(--space-2); &:focus-visible { outline: /* ⑯ */; /* anillo de 3px del color de marca */ outline-offset: 3px; } }

Guía de huecos

#ZonaDescripción visual / funcional
1 cabecera
El título usa la tipografía serif del design system (Playfair Display)
Token --font-display
2 cabecera
El subtítulo aparece en gris apagado, no negro
3 campo
El div.campo necesita ser el punto de anclaje para su mensaje de error (::after posicionado)
4 campo
El contenido del ::after que añade el asterisco al final del label
Cadena con un espacio y el carácter *
5 campo
El asterisco usa el color corporativo de HANA (rojo vino)
6 campo
El texto de sugerencia (placeholder) aparece en un gris muy claro, casi beige
hsl(40 10% 68%) o valor similar de baja saturación
7 campo
El placeholder va en cursiva, diferenciándose del texto real
8 foco
Al tabular hasta el campo, el borde adopta el color de marca de HANA
9 foco
Un halo suave rodea el campo: 3px de ancho, color de marca al 15% de opacidad
box-shadow: 0 0 0 3px hsl(… / 0.15)
10 error
Cuando el campo tiene un valor incorrecto y pierde el foco, el borde se vuelve rojo
Token --color-error
11 error
El fondo del campo en error es un rosa muy suave (casi blanco)
Token --color-error-lt
12 error
El mensaje de error se obtiene del atributo HTML del div.campo, no está escrito en el CSS
content: attr( … )
13 campo
Los campos de fecha y hora muestran un cursor que indica que son clickables
14 campo
El textarea solo puede hacerse más alto arrastrando, no más ancho
15 botón
El botón ocupa todo el ancho del formulario
16 botón
Al tabular hasta el botón aparece un anillo de 3px del color de marca
outline: 3px solid var(…)

Cómo entregar

  • Crea ut02-p5c.html y ut02-p5c.css. Usa el HTML dado en este documento, vincula la hoja de estilos y completa los 16 huecos.
  • Prueba con el teclado: usa Tab para moverte entre campos, escribe un correo incorrecto y haz clic fuera del campo.
  • Comprime en ut02-p5c_apellido.zip y sube a la tarea del aula virtual.
