CSS que debes completar — 16 huecos

/* ─── ZONA 1: section.menu ─── */ .menu { padding: var(--space-10) 0; /* espacio vertical generoso */ background: var(--color-surface); } .menu__contenedor { max-width: 1100px; margin: /* ① */; /* centrado horizontal */ padding: 0 var(--space-6); } /* ─── ZONA 2: header.menu__cabecera ─── */ .menu__cabecera { text-align: /* ② */; /* título y subtítulo centrados */ margin-bottom: var(--space-8); } .menu__titulo { font-family: var(--font-display); font-size: /* ③ */; /* grande pero no excesivo */ font-weight: 700; color: var(--color-ink); margin-bottom: var(--space-2); } .menu__subtitulo { font-size: var(--text-base); color: /* ④ */; /* texto atenuado */ } /* ─── ZONA 3: div.menu__filtros ─── */ .menu__filtros { display: /* ⑤ */; gap: var(--space-2); justify-content: /* ⑥ */; /* botones centrados en fila */ flex-wrap: /* ⑦ */; /* si no caben, saltan a la línea */ margin-bottom: var(--space-8); } .menu__filtro { padding: var(--space-2) var(--space-5); border: 1px solid var(--color-border); border-radius: 100px; /* píldora */ background: transparent; cursor: pointer; transition: background 0.15s, color 0.15s, border-color 0.15s; /* Estado activo */ &--activo { background: /* ⑧ */; /* fondo de marca */ color: white; border-color: /* ⑨ */; /* mismo que el fondo */ } /* Hover solo en los NO activos */ &:not(.menu__filtro--activo):hover { background: var(--color-brand-lt); border-color: /* ⑩ */; /* borde de marca al pasar */ color: var(--color-brand); } } /* ─── ZONA 4: div.menu__grid ─── */ .menu__grid { display: /* ⑪ */; grid-template-columns: /* ⑫ */; /* ↑ columnas automáticas: mínimo 260px, máximo 1fr se crean y destruyen solas al cambiar el ancho */ gap: /* ⑬ */; /* espacio entre cards */ } /* ─── ZONA 5: article.card dentro del grid ─── */ .card { background: var(--color-surface); border-radius: var(--radius-md); overflow: /* ⑭ */; /* la imagen no se sale del borde redondeado */ box-shadow: var(--shadow-sm); transition: transform 0.2s, box-shadow 0.2s; &:hover { transform: /* ⑮ */; /* sube 4px al pasar el ratón */ box-shadow: var(--shadow-md); } } .card__imagen { width: 100%; aspect-ratio: 4 / 3; object-fit: /* ⑯ */; /* recorta sin deformar */ }

Cómo entregar

  • Crea un archivo ut02-p4c.css y escribe únicamente los valores de los 16 huecos (una propiedad por línea, con el selector correspondiente como comentario).
  • No modifiques el HTML dado. No copies código de la práctica guiada.
  • Comprueba en el navegador que el grid realmente cambia de columnas al redimensionar la ventana.
  • Comprime el proyecto en ut02-p4c_apellido.zip y súbelo a la tarea del aula virtual.
